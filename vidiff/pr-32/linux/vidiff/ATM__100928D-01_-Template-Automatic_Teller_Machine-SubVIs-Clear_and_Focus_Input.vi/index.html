Clear and Focus Input.vi

Empties a string control and gives it the key focus, so the user can type the next entry straight away. Used by the ATM main VI on User Input whenever it asks for an account number or an amount. The control must be enabled first: a disabled control takes no key focus. Writing Value fires no Value Change event.

Error behaviour: if error in carries an error, the control is not changed and the error is passed to error out.
