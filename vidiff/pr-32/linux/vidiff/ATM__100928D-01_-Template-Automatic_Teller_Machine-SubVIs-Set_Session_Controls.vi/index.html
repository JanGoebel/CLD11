Set Session Controls.vi

Enables or disables the ATM front-panel controls for one UI Mode, so the main VI needs no property nodes for it. Session Controls is an array of control references in this fixed order: Card Simulator, User Input, Enter, Left Buttons, Right Buttons, Left Menu, Right Menu. Each control is set to Enabled or to Disabled and Grayed Out: Waiting for Card enables only Card Simulator; Card Inserted enables User Input and Enter; Menu Active enables User Input, Enter, both menus and both button clusters; Session Ended disables everything. A missing reference is skipped by LabVIEW with an error.

Error behaviour: if error in carries an error, no control is changed and the error is passed to error out.
