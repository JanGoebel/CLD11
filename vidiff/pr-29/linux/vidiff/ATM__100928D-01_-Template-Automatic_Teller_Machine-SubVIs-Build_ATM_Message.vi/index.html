Build ATM Message.vi

Builds the text the ATM shows on its display for one Message Type. Main Menu takes the customer name from Account, Balance Inquiry the balance from Account, and Deposit Complete / Withdrawal Complete the money value from Amount. Money is formatted with a dollar sign and two decimals, always with a period as decimal separator. Pure string building: no file or user interface access.

Error behaviour: if error in carries an error, nothing is built, ATM Message is empty and the error is passed to error out unchanged.
