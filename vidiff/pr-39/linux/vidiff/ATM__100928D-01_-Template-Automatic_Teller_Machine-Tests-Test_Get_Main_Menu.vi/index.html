Test Get Main Menu.vi

Caraya unit test for Get Main Menu.vi (feature #47: Fast Cash $100 replaces the reserved None item).

Get Main Menu.vi is called once. The expected menu is ONE constant, an instance of the typedef ATM Menu.ctl, so it follows the typedef when the states enum grows. Do not replace it with an unlinked copy: Caraya compares the enum's item list too. The expected value of a single item is unbundled from that same constant.

Row 1: the top left item (Left, Item 1) is labelled Fast Cash $100 and its action is the state Fast Cash $100.

Row 2: the bottom right item (Right, Item 3) is still labelled Fast Cash $50 and its action is still the state Fast Cash.

Row 3: the whole menu equals the specified six items, none of which has the action None any more.

Every assertion takes its error in from Define Test rather than from the assertion before it, so a failing row cannot stop a later one. The error cluster carries the FIRST failure only. Read the JUnit report for all of them.
