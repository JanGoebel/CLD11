Test Withdraw Funds Fast Cash 100.vi

Caraya unit test for Withdraw Funds.vi with the amount of the Fast Cash $100 menu item (feature #47). The Fast Cash $100 state of the main VI calls Withdraw Funds.vi with Amount 100, exactly as Fast Cash $50 does with 50.

Every case starts from its own fresh copy of the specification accounts file (Create Accounts Fixture.vi, written under Tests\results), so the real ATM accounts.txt is never touched and the cases can run in parallel. The balance is always checked by reading the file back with Get Account.vi. The expected records are instances of the typedef ATM Account.ctl.

Case 1: withdrawing 100 from 23456 (balance 1000) succeeds and the file holds 900.

Case 2: account 12345 (balance 550) is first brought down to 50 by withdrawing 500, the set-up step. Withdrawing 100 is then refused (Sufficient Funds? FALSE) and the file still holds 50 - the Withdrawal Failed path.

The error cluster carries the FIRST failure only. Read the JUnit report for all of them.
