Parse Amount.vi

Converts the text the user typed into a money amount. Leading and trailing whitespace is removed, then the whole remaining text must be one number with a period as decimal separator (independent of the system locale), finite and greater than zero. Valid Amount? is TRUE and Amount carries the number when it is; otherwise Valid Amount? is FALSE and Amount is 0. Invalid input is NOT an error - error in is passed through to error out unchanged so the caller can show a message. No file access.
