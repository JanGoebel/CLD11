Get Account.vi

Reads the accounts file and returns the record of one account, so the balance always comes from the file. Account Found? is FALSE with an empty record when the number is not in the file (not an error). Errors of Read Accounts.vi (5001 for an empty path, file errors) are returned in error out; when error in carries an error the file is not read.
