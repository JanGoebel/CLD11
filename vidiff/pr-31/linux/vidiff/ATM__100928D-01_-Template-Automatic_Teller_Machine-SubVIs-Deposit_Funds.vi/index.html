Deposit Funds.vi

Deposits Amount into an account. The CURRENT balance is read from the accounts file (Get Account.vi), Amount is added and the new balance is written back with Update Account Balance.vi; Account returns the updated record. An account number that is not in the file returns error 5003 and nothing is written. When error in carries an error the file is neither read nor written.
