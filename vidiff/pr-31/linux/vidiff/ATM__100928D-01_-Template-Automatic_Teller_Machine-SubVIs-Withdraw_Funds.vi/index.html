Withdraw Funds.vi

Withdraws Amount from an account (also used for Fast Cash with Amount 50). The CURRENT balance is read from the accounts file (Get Account.vi). When the balance is at least Amount, Amount is subtracted, the new balance is written with Update Account Balance.vi and Sufficient Funds? is TRUE. Otherwise nothing is written and Sufficient Funds? is FALSE - that is not an error. An account number that is not in the file returns error 5003 and nothing is written. When error in carries an error the file is neither read nor written.

Sufficient Funds?

TRUE when the account was found and its balance covered Amount, so the withdrawal was written. FALSE otherwise (nothing written).
