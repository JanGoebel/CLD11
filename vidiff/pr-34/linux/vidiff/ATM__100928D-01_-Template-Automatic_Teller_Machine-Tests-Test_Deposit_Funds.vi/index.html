Test Deposit Funds.vi

Caraya unit test for Deposit Funds.vi. Every case starts from its own fresh copy of the specification accounts file (Create Accounts Fixture.vi, written under Tests\results), so the real ATM accounts.txt is never touched and the cases can run in parallel.

Case 1: depositing 100 into 12345 (balance 550) returns the record with balance 650 AND the file holds 650 afterwards (read back with Get Account.vi).

Case 2: depositing into the unknown account 99999 returns error 5003.

The error cluster carries the FIRST failure only. Read the JUnit report for all of them.
