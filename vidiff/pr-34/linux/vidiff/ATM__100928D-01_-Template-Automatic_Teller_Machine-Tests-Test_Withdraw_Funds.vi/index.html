Test Withdraw Funds.vi

Caraya unit test for Withdraw Funds.vi. Every case starts from its own fresh copy of the specification accounts file (Create Accounts Fixture.vi, written under Tests\results), so the real ATM accounts.txt is never touched and the cases can run in parallel. The balance is always checked by reading the file back with Get Account.vi.

Case 1: withdrawing 50 from 23456 (balance 1000) succeeds and the file holds 950.

Case 2: withdrawing 800 from 34567 (balance 750) is refused (Sufficient Funds? FALSE) and the file still holds 750 - the exam's Withdrawal Failed path.

Case 3: withdrawing the exact balance 550 from 12345 is allowed and leaves 0.

The error cluster carries the FIRST failure only. Read the JUnit report for all of them.
