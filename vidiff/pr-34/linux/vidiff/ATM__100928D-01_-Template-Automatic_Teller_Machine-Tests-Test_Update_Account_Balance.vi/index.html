Test Update Account Balance.vi

Caraya unit test for Update Account Balance.vi (and Read Accounts.vi, which reads the result back). Every case starts from its own fresh copy of the specification accounts file (Create Accounts Fixture.vi, written under Tests\results), so the real ATM accounts.txt is never touched.

Case 1: setting 45678 to 1000.5 changes exactly that record - all four records are read back and compared, so a corrupted line, a lost record or a rounded balance fails.

Case 2: an unknown account returns error 5002.

The error cluster carries the FIRST failure only. Read the JUnit report for all of them.
