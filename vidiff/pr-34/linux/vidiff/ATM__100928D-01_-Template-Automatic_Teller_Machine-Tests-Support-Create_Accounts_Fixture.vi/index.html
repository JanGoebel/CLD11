Create Accounts Fixture.vi

Test support for the ATM Caraya tests. Writes a fresh accounts file with the four records of the exam specification (12345 John Doe 550, 23456 Jennifer Rodriguez 1000, 34567 Bryan Smith 750, 45678 Julie Ramirez 900) to Tests\results\<Fixture Name>.txt and returns its path. The results folder is located relative to this VI (one folder up from Support) and created when missing, so the tests run from any checkout location. An existing fixture file is replaced, so every test starts from the same state. Give every test case its own Fixture Name: Caraya runs the cases of one test VI in parallel.
