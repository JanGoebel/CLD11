Test Get Account.vi

Caraya unit test for Get Account.vi (which reads the file with Read Accounts.vi and looks the number up with Find Account.vi). Every case reads its own fresh copy of the specification accounts file (Create Accounts Fixture.vi, written under Tests\results), so the result does not depend on balances changed by running the ATM.

Case 1: account 23456 is found with its full record from the file.

Case 2: the unknown account 00000 is not found, and that is not an error (code 0).

The error cluster carries the FIRST failure only. Read the JUnit report for all of them.
