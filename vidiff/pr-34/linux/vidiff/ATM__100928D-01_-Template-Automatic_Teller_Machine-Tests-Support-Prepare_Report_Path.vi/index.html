Prepare Report Path.vi

Test support for the ATM Caraya runner. Returns the absolute path of Tests\results\<Report File Name>, located relative to this VI (one folder up from Support), creates the results folder when it is missing and deletes a report left by an earlier run, so a report found after the run was written BY that run. A missing folder or a missing old report is not an error.
