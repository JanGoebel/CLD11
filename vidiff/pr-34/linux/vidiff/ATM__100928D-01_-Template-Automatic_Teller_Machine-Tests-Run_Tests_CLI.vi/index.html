Run Tests CLI.vi

Headless Caraya runner for CI. Runs every ATM unit test VI in this folder through Caraya's Run Tests.vi with Interactive FALSE (no dialog) and writes a JUnit XML report to results\caraya-report.xml next to this VI. The results folder is created when missing and an old report is deleted first, so the report is always from this run.

Connector pane follows LabVIEW CLI's RunVI contract - do not change it:

Command Line Arguments (input, unused)

Exit Code: 0 when every test passed, 1 when any test failed, Caraya returned an error, or no report was written

Output: one-line verdict, Caraya's error code and the report path

Usage:

LabVIEWCLI -OperationName RunVI -VIPath <this VI> -LabVIEWPath <LabVIEW.exe> -PortNumber 3364

The test VIs are found relative to this VI, so the folder can be checked out anywhere.
