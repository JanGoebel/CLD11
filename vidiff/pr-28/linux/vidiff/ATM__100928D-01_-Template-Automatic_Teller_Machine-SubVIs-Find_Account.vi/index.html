Find Account.vi

Searches an array of ATM Account records for the given Account Number. Both the searched number and the stored numbers are trimmed of whitespace and compared exactly. Returns Account Found? TRUE with the record and its array index, or FALSE with an empty record and Index -1. Pure function, no file access; error in is passed through to error out.
