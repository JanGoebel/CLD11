Update Account Balance.vi

Sets the balance of one account in the ATM accounts file (read-modify-write). All records are read with Read Accounts.vi, the account is located with Find Account.vi, only its Balance is replaced, and the whole file is written back in the same CSV format (Account Number,First Name,Last Name,Balance; one record per line, LF line endings). Balance is written with a period as decimal separator and without trailing zeros (550 -> 550, 1000.5 -> 1000.5). If the account is not in the file, error 5002 is returned and the file is left untouched. The file reference is always closed.

 Accounts File Path

Absolute path of the accounts file (ATM accounts.txt). An empty path returns error 5001 and nothing is written.

Account Number

Account number (5 digits) whose balance is changed. Leading and trailing whitespace is ignored.

New Balance

New balance of the account, written to the file without trailing zeros.
