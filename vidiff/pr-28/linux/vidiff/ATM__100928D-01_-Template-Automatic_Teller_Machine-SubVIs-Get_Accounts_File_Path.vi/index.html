Get Accounts File Path.vi

Returns the absolute path of the ATM accounts file (ATM accounts.txt). The file sits next to the main ATM VI, one folder above the SubVIs folder that holds this VI, so the path is built from this VI's own path - no file dialog is ever shown. error in is passed through unchanged to error out.
