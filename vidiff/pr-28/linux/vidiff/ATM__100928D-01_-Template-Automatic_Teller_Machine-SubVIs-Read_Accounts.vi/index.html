Read Accounts.vi

Reads the ATM accounts file (CSV, no header, one record per line: Account Number,First Name,Last Name,Balance) and returns every record as an array of ATM Account clusters. Every field is trimmed of whitespace, Balance is parsed as a number with a period as decimal separator, and empty lines are skipped. An empty Accounts File Path returns error 5001 instead of reading, so no file dialog can ever open. A missing or unreadable file returns the file error and an empty array.
