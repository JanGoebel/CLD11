Get Menu Action.vi

Looks up which state the ATM state machine must run when a function button is pressed. Takes the menu currently shown (ATM Menu.ctl), the side the button is on (Right Side?) and its Button Index, and returns the Action of that menu item. A Button Index outside 0..2 (for example -1 from Get Pressed Button Index.vi when nothing is pressed) returns None.

Error behaviour: error in is passed to error out unchanged; the action is computed in every case.

Right Side?

FALSE: the button is one of the Left Buttons. TRUE: one of the Right Buttons.

Button Index

Index of the pressed button on that side, 0..2 top to bottom. Any other value returns None.
