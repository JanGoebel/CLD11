Get Main Menu.vi

Returns the ATM Main Menu as data: for each of the six function buttons the label shown beside it and the state the main state machine runs when it is pressed. Left side: None, Balance Inquiry, Return Card and Terminate. Right side: Deposit, Withdraw, Fast Cash $50. To change the menu, edit the Main Menu constant; the main state machine needs no change.

Error behaviour: error in is passed to error out unchanged; the menu is returned in every case.
