Get Pressed Button Index.vi

Takes one of the ATM front-panel function button clusters (Left Buttons or Right Buttons) and returns the index of the button that is TRUE: 0 for the top button, 1 for the middle, 2 for the bottom. Returns -1 when no button is TRUE. If several are TRUE the topmost one wins.

Error behaviour: error in is passed to error out unchanged; the index is computed in every case.
