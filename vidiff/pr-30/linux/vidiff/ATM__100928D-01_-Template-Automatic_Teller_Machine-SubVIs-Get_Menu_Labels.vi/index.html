Get Menu Labels.vi

Takes a menu (ATM Menu.ctl) and returns the button labels of its Left and Right side as the two string clusters the ATM front panel shows beside the function buttons (Left Menu and Right Menu). Element order is Item 1, Item 2, Item 3, top to bottom, so the outputs wire straight into the front-panel indicators.

Error behaviour: error in is passed to error out unchanged; the labels are returned in every case.
